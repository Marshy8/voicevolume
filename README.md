# VoiceVolume
This react application was a joint project by [justunator](https://github.com/justunator) and [marshy8](https://github.com/Marshy8). It was built to  be used in the classroom to help young students visualize their volume level.

---

## Dev Split
### [justunator](https://github.com/justunator)  
  - Main focus is on the functionality of the application.
### [marshy8](https://github.com/Marshy8)
  - Main focus in on the look and feel of the application.

---

## How to Run on Your Machine
    npm install
    npm run dev
